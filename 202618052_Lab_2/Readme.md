# DS602 Lab 2 - Probability Models and Disease Spread

## Overview
This repository contains the DS602 Lab 2 submission for probabilistic modeling and simulation. The notebook explores the Monty Hall problem, Pólya's urn processes, and the SIR epidemiological model using Python simulation and visualization.

## Contents
- `202618052_Assignment02_DS602.ipynb`: Jupyter notebook presenting the analysis, simulation code, plots, and answers for all problems.
- `Readme.md`: Project description, methodology, and usage notes.

## Problems Covered
1. **Monty Hall Problem**: Simulates the classic conditional probability game and compares win rates for stay versus switch strategies.
2. **Pólya’s Urn**: Studies belief dynamics using urn models, including single-trajectory behavior, limiting distributions, and the effect of different initial ball counts.
3. **SIR Disease Spread Model**: Develops recurrence relations for the SIR model, compares empirical urn-based simulation with theoretical predictions, and analyzes intervention scenarios such as reduced transmission, faster recovery, and vaccination.

## Methodology
- Uses `numpy` and `matplotlib` for simulation, computation, and plotting.
- Implements repeated trials for Monte Carlo estimation and empirical observation.
- Compares simulation results to analytic or theoretical behavior where applicable.
- Visualizes trajectories, histograms, and epidemic curves to highlight key concepts.
